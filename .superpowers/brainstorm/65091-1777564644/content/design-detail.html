Hub view accordion behavior: Tap a project header → expands to show session pills + up to 5 most-recent conversations. Tap "See all N conversations →" → new screen with full conversation list for that project. Tap header again → collapse. Only one project expanded at a time (or allow multiple — TBD).
Session Status Display in Hub View
Status pills in the sessions strip
● In Progress
◑ Idle
○ Empty

• In Progress = session is actively running (maps to existing running status)

• Idle = session exists but paused / waiting input (maps to idle + waiting_input)

• Empty = session started but never sent a prompt (promptCount === 0 + not running)

• failed and completed keep their existing labels in the pill; shown as smaller secondary pills
