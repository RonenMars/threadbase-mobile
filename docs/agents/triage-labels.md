# Triage labels

**The vocabulary is canonical in [`threadbase/docs/triage-labels.md`](https://github.com/RonenMars/threadbase/blob/main/docs/triage-labels.md).**
Read that file for the label meanings, their colours, the rule that they are additive to priority, type and area rather than a substitute, and the two near-collisions worth naming — `question` the type versus `needs-info` the state, and `wontfix` serving both roles at once.

This file records only what is true of *this* repo.

All five labels exist on `RonenMars/threadbase-mobile`.
`wontfix` predates this setup; `needs-triage`, `needs-info`, `ready-for-agent` and `ready-for-human` were created on 2026-08-14.
`threadbase-streamer` adopted the same five at the same colours on 2026-08-20, so the two trackers are interchangeable to a reader moving between them.

When a skill mentions a triage role — "apply the AFK-ready triage label" — use the label string from the canonical table.
