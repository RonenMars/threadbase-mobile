# Lessons

Hard-won findings from working on tb-mobile — root causes, surprising platform behaviors, recurring traps. Add a new entry whenever a non-obvious problem cost real time to diagnose, so the next person (or the next session) doesn't have to repeat the work.

Entries are dated and topic-named. Each one should answer:

1. What the symptom looked like
2. What we ruled out
3. The actual cause (if found)
4. What to do — or not do — next time
