# Ukrainian (`uk`) language adapter

Use modern standard Ukrainian, native autonym `Українська`, LTR, with `uk-UA` recognition where appropriate. Translate directly from English, not Russian. Avoid Russianisms, Surzhyk, calques and overly bureaucratic phrasing. Use consistent register, concise infinitive action labels where natural, and gender-neutral constructions when feasible. Follow current Ukrainian orthography and consistent apostrophe typography. Avoid forcing inflection of runtime names.

Starting glossary (context overrides; ensure consistency): session — сесія; AI agent — ШІ-агент; prompt — промпт or запит; tool call — виклик інструмента; repository — репозиторій; branch — гілка; commit — коміт; settings — налаштування; resume session — продовжити сесію; retry — спробувати ще раз; encryption — шифрування. Distinguish запит from instruction/system prompt if the product does. Preserve recognizable product names.

Cardinal CLDR categories: `one`, `few`, `many`, `other`. For integers, one applies to endings 1 except 11; few to endings 2–4 except 12–14; many to other integers. Fractional values generally use other; verify actual runtime behavior and displayed precision. Test 0, 1, 2, 4, 5, 11, 12, 14, 21, 22, 25, 101, 111 and 1.5. Example: 1 сесія, 2 сесії, 5 сесій, 1,5 сесії. Use actual message syntax, not hard-coded English plural forms. Check ordinal rules separately if used. Use locale-aware date, number and relative-time formatters. Review grammatical agreement around dynamic counts, technical terminology and error/permission messages particularly closely.
